# Фізичні константи в транзисторі: шум між 0 і 1

**Дата:** 2026-09-20  
**Статус:** дослідницька нотатка / research note  
**Контекст:** розмова про межу між фізикою і семантикою в `wsm-os`

---

## Основне спостереження

Цифрова схемотехніка використовує транзистор неправильно — точніше, неповно.

Транзистор має **три режими роботи**, ми свідомо обмежуємось двома крайніми:

```
Відсічка (cut-off)    → 0    ← цифрова логіка
Насичення (sat)       → 1    ← цифрова логіка
Активна зона          → будь-яке значення між 0 і Vdd  ← ігнорується
```

В активній зоні транзистор — неперервний підсилювач, не перемикач.
Ми штучно зламуємо цю властивість заради шумостійкості й відтворюваності.
Ціна: **фізична реальність транзистора відкидається** на користь зручної абстракції.

---

## Де живуть реальні фізичні константи

### 1. Субпорогова зона (subthreshold regime)

Коли транзистор працює нижче порогової напруги `Vt`, струм стоку не нульовий:

```
I_ds = I₀ · exp(Vgs / n·Vt)

де:
  Vt = kT / q          — теплова напруга
  k  = 1.38×10⁻²³ J/K  — стала Больцмана (РЕАЛЬНА КОНСТАНТА ВСЕСВІТУ)
  T  = температура в Кельвінах (РЕАЛЬНИЙ СТАН СЕРЕДОВИЩА)
  q  = 1.6×10⁻¹⁹ Кл    — заряд електрона (РЕАЛЬНА КОНСТАНТА ВСЕСВІТУ)
  n  = коефіцієнт нахилу підпорогової характеристики (~1.2–1.5)
```

Це не модель константи. Це сама константа — `k`, `T`, `q` — буквально
в провідності транзистора. Транзистор не "знає" сталу Больцмана —
він **є** її фізичним проявом.

**Висновок для wsm-os:** субпорогова зона — це місце де фізика світу
безпосередньо записана в апаратний результат, без жодної апроксимації
людиною.

---

### 2. Метастабільність — транзистор що не може вирішити

Flip-flop, якому подають сигнал точно на межі тактового фронту, потрапляє
в **метастабільний стан**: він фізично знаходиться між 0 і 1 протягом
випадкового часу, що визначається тепловим шумом.

```
Час виходу з метастабільності:
  τ_meta = τ₀ · exp(t_r / τ_c)

де τ_c залежить від конкретного транзистора і температури.
```

Це не похибка — це **читання теплового шуму через структуру самого залізо**.

На x86 цей ефект використовується в апаратному генераторі випадкових чисел:

```asm
RDRAND rax    ; читає справжній фізичний шум — не псевдовипадкове число
```

---

### 3. Кільцевий осцилятор (ring oscillator)

Непарна кількість інверторів з'єднаних в кільце утворює генератор,
що коливається з частотою яка залежить від:

- температури (через рухливість носіїв заряду)
- напруги живлення
- варіацій виробничого процесу (унікальних для кожного кристалу)

Два незалежних кільцевих осцилятори ніколи не синхронізуються ідеально —
різниця їхніх фаз і є "шум між 0 і 1", зчитаний у вигляді бітів.

---

## Що це означає для wsm-os

Правило `wsm-os` каже:

```
wsm:    "нам потрібна операція X"
            ↓
wsm-os: "ось чи можна її реалізувати і якою ціною"
```

Питання яке виникає тут інше:

```
wsm:    "нам потрібна фізична константа C"
            ↓
wsm-os: "ось де C вже живе в залізі — без апроксимації"
```

Субпорогова зона — це місце де `wsm`-операції потенційно можуть
**читати реальний стан фізичного світу** (температуру через `kT/q`)
без того щоб людина вводила значення вручну.

---

## Практичні підходи до "шуму між 0 і 1"

| Метод | Що читається | Доступність на x86 |
|---|---|---|
| `RDRAND` | Тепловий шум через метастабільність | Пряма інструкція |
| Ring oscillator sampling | Температура, варіації fab | Потребує доступу до лічильників або GPIO |
| ADC на аналоговому вході | Пряма аналогова напруга | Зовнішній чіп або мікроконтролер |
| Subthreshold current | `kT/q` буквально в струмі | Потребує спеціального режиму живлення |
| RDTSC jitter між ядрами | Теплові варіації частоти | Пряма інструкція, непрямо |

## Відкрите питання для wsm-os

Де саме на цій машині (Intel Core i5-6400) знаходиться **перша точка**
де `kT` читається без апроксимації?

Кандидати для дослідження:
- Intel TRNG (через `RDRAND` / `RDSEED`) — задокументований, але "чорна скриня"
- MSR регістри теплового датчика (`IA32_THERM_STATUS`) — температура через `rdmsr`
- Subthreshold behaviour через `cpufreq` варіації при знижені напруги

Це питання залишається відкритим до наступного milestone.
